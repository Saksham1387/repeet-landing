# Repeet — landing page

The marketing site for [Repeet](https://github.com/Saksham1387/Repeet), a local-first Chrome extension that turns accepted LeetCode submissions into a spaced-repetition revision deck.

Built with Next.js, React, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run lint
npm run build
npm start
```

## Structure

- `app/page.tsx` — landing page content
- `app/components/ascii-bloom.tsx` — generated ASCII artwork
- `app/globals.css` — theme tokens, grain, and motion
- `app/layout.tsx` — fonts and metadata
